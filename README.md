# 🎡 SpinWheel

Простое, но продуманное **колесо фортуны** на Vue.js: крутишь — получаешь случайный приз.  

🔗 **Демо**: [https://nigilen.github.io/kolino__spin-wheel/](https://nigilen.github.io/kolino__spin-wheel/)

---

### 💡 Особенности

- **Семантичная вёрстка** — даже в интерактивных проектах важно думать о структуре.
- **Стилизация по методологии БЭМ** — для читаемости и масштабируемости CSS.
- **Полностью адаптивный дизайн** — работает на мобильных благодаря «резиновой» вёрстке.
- **Все иконки и графика — в SVG** — чётко выглядят на любом экране и легко кастомизируются.
- **Данные вынесены отдельно** — список призов хранится в отдельном файле, что упрощает настройку без правки компонентов.

---

### 🛠 Технологии

- **Vue 3** (Composition API)
- **HTML5 / CSS3 / JavaScript (ES6+)**
- **Figma** — макет и иконки созданы самостоятельно
